# Сімейний бюджет

Простий офлайн-застосунок (PWA) для обліку сімейних доходів, витрат і накопичень.

- Усі дані зберігаються лише на пристрої користувача (localStorage, фото чеків — IndexedDB). Жодних серверів, аналітики чи сторонніх бібліотек. Єдиний мережевий запит — курс євро НБУ (з запасним варіантом monobank) за кнопкою.
- Встановлюється з браузера на головний екран iPhone (Safari) та Android (Chrome), працює без інтернету.
- План на місяць: очікуваний дохід, щомісячні обов'язкові платежі й разові покупки, залишок «на все інше».
- Нагадування про платежі (на Головній, сповіщення браузера, файл календаря .ics), ліміти на категорії, прогноз накопичення цілей, порівняння з минулим місяцем.
- Швидке додавання: часті витрати одним дотиком зі скасуванням, калькулятор у полі суми, «повторити», фото чека.
- Імпорт виписки банку (CSV, xlsx, HTML-«xls»): автокатегорії за MCC, назвою магазину і запам'ятованими правилами (`data.rules`), захист від дублів (`importKey`).
- Спільний бюджет: обмін файлом між телефонами з об'єднанням без дублів (`data.deleted` для видалень, `updated` для правок), поле «хто платив».
- Рахунки з початковими залишками і переказами (`data.accounts`, `data.transfers`), вибір теми, знайомство при першому запуску, підсумок місяця картинкою.
- Експорт в Excel (.xlsx) і резервна копія/відновлення (.json), надсилання копії через меню «Поділитися».

Інструкція для користувача: `guide.html`.

Після зміни файлів збільште номер версії `CACHE` у `sw.js`, щоб телефони отримали оновлення.
