# Сімейний бюджет

Простий офлайн-застосунок (PWA) для обліку сімейних доходів, витрат і накопичень.

- Усі дані зберігаються лише на пристрої користувача (localStorage). Жодних серверів, аналітики чи сторонніх бібліотек.
- Встановлюється з браузера на головний екран iPhone (Safari) та Android (Chrome), працює без інтернету.
- Експорт в Excel (.xlsx) і резервна копія/відновлення (.json).

Інструкція для користувача: `guide.html`.

Після зміни файлів збільште номер версії `CACHE` у `sw.js`, щоб телефони отримали оновлення.
